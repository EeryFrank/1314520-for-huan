# 1314520 for Huan

“1314520 · 一生一世我爱你”七夕星空动画。数字由函数曲线绘制，点击或轻触夜空会升起爱心。

## 运行

这是无构建步骤、无第三方运行依赖的静态网页源码。可以直接打开 `index.html`，也可以在仓库目录启动任意静态文件服务器。

```powershell
python -m http.server 8000
```
